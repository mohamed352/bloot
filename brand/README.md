# Bloot Brand Assets

This directory contains brand assets for the Bloot app.

## Required Assets

### Logo Variants
- `logo_primary.svg` — Full logo (icon + "BLOOT" wordmark) for dark backgrounds
- `logo_icon.svg` — Icon only (card-themed symbol)
- `logo_horizontal.svg` — Icon + wordmark in horizontal layout
- `logo_stacked.svg` — Icon above wordmark, centered

### App Icons
- `app_icon_ios.png` — 1024x1024px for App Store
- `app_icon_android.png` — 512x512px for Google Play
- `app_icon_foreground.svg` — Adaptive icon foreground
- `app_icon_background.svg` — Adaptive icon background (#0A0A0F)

### Splash Screens
- `splash_dark.png` — Logo centered on #0A0A0F background

### Brand Guidelines
- See `branding/` directory for complete brand documentation
