# Bloot — Logo Creation Guide

## Overview

The Bloot logo must communicate three things instantly: **premium**, **social**, and **Balout**. It should work across all contexts — from a 16px app icon to a 3-meter event banner — and feel equally at home in Arabic and English contexts.

---

## Logo Variants

### 1. Primary Logo: Icon + Wordmark

The primary logo consists of the Bloot icon (card-themed mark) alongside the "BLOOT" wordmark.

```
┌─────────────────────────────┐
│                             │
│    [ICON]    BLOOT          │
│                             │
└─────────────────────────────┘
```

- Icon: 1 unit height
- Wordmark: 0.8 unit height
- Gap between icon and wordmark: 0.3 units
- Wordmark uses Inter Bold, ALL CAPS, letter-spacing: 0.08em
- Total aspect ratio: approximately 3.5:1 (horizontal)

**Usage:** App splash screen, website header, social media profiles, marketing materials, business cards.

---

### 2. Icon Only (Mark)

The Bloot icon is a stylized representation of a Balout card, designed to be recognizable at any size.

```
┌───────────┐
│           │
│   [ICON]  │
│           │
└───────────┘
```

**Icon Design Principles:**
- Represents a card form factor (rectangular, portrait orientation)
- Contains a subtle "B" letterform integrated into the card design
- Incorporates the Bloot purple (#8B5CF6) as the primary color
- Gold (#F59E0B) accent element (a corner flourish or suit symbol)
- Works at 16px minimum size
- Distinguishable from generic playing card icons

**Usage:** App icon, favicon, social media avatar, notification badge, watermark.

---

### 3. Horizontal Layout

Icon on the left, wordmark on the right. This is the most common layout.

```
[ICON] BLOOT
```

**Specifications:**
- Icon height: 48px (at 1x)
- Wordmark height: 38px (at 1x)
- Gap: 16px
- Wordmark vertically centered with icon
- Minimum width: 200px

**Usage:** Website header, email header, presentation slides, video outro, sponsor banner.

---

### 4. Stacked Layout

Icon on top, wordmark below. Used in vertical/square spaces.

```
   [ICON]

   BLOOT
```

**Specifications:**
- Icon width: 64px (at 1x)
- Wordmark height: 24px (at 1x)
- Gap: 12px
- Wordmark horizontally centered with icon
- Minimum height: 120px

**Usage:** Social media posts (square), app store featured graphics, event signage, merchandise.

---

### 5. Arabic Wordmark

For Arabic-language contexts, the wordmark uses "بلوت" in Cairo Bold.

```
[ICON] بلوت
```

**Specifications:**
- Same proportions as English wordmark
- Font: Cairo Bold (700)
- Letter-spacing: 0 (never add letter-spacing to Arabic)
- Applied to both horizontal and stacked layouts
- RTL layout: icon on the RIGHT side, text flows left

**Usage:** Any Arabic-language context — Arabic website, Arabic social media, Arabic marketing materials.

## Color Variants

### On Dark Background (Primary)

The default and primary usage. The Bloot logo was designed for dark backgrounds.

```
Icon:       #8B5CF6 (Purple 500) with #F59E0B (Gold 500) accent
Wordmark:   #FFFFFF (White)
Background: #0A0A0F (Bloot Black)
```

This is the preferred variant and should be used whenever possible.

---

### Monochrome White

For use on dark backgrounds where color is not available (embossing, engravings, single-color prints).

```
Icon:       #FFFFFF (White)
Wordmark:   #FFFFFF (White)
Background: Any dark background
```

---

### Monochrome Gold

For premium applications, special editions, and VIP contexts.

```
Icon:       #F59E0B (Gold 500)
Wordmark:   #F59E0B (Gold 500)
Background: #0A0A0F (Bloot Black)
```

**Usage:** VIP events, premium partnerships, Eid/Ramadan campaigns, trophy engravings.

---

### On Light Background (Limited Use)

For situations where a dark background is not possible (sponsored placements, some print contexts).

```
Icon:       #7C3AED (Purple 600) with #D97706 (Gold 600)
Wordmark:   #171717 (Gray 900)
Background: #FFFFFF (White) or light surface
```

**Note:** Light background usage should be avoided where possible. The dark variant is strongly preferred.

## Minimum Sizes

| Variant | Minimum Width | Minimum Height | Notes |
|---------|---------------|----------------|-------|
| Horizontal (Icon + Wordmark) | 200px | 48px | Wordmark must be legible |
| Stacked (Icon over Wordmark) | 80px | 120px | Wordmark must be legible |
| Icon Only | 24px × 24px | 24px | Must be recognizable |
| Arabic Wordmark Horizontal | 180px | 48px | Arabic must be legible |
| App Icon | 1024px × 1024px | 1024px | Source file (scales down) |
| Favicon | 32px × 32px | 32px | Icon only |

### Legibility Rules

- **Below 200px width:** Consider switching to stacked layout or icon-only
- **Below 120px width:** Icon only — wordmark becomes illegible
- **Below 24px:** Use simplified icon (reduce detail)
- **Arabic wordmark:** Requires slightly more minimum width than English (Arabic is denser at small sizes)

## Clear Space

### Minimum Clear Space

The clear space around the logo must be at least **1x the icon height** on all sides.

```
         ┌───────────────────────┐
         │     Clear Space (1x)   │
         │   ┌─────────────────┐  │
         │   │                 │  │
1x ──────┤   │    [ICON]       │  │
         │   │    BLOOT        │  │
         │   │                 │  │
         │   └─────────────────┘  │
         │     Clear Space (1x)   │
         └───────────────────────┘
```

**Rules:**
- Clear space is measured from the icon height (not the total logo height)
- No other logos, text, or graphic elements may enter the clear space
- Background color may extend into the clear space
- Edges of photos, borders, and dividing lines must not enter the clear space

### Adjacent Logos

When placing Bloot's logo next to partner/sponsor logos:
- Minimum separation: **2x icon height**
- Both logos should be optically centered (not mathematically centered)
- Bloot logo should be equal or larger in visual weight

## Incorrect Usage

### NEVER Do Any of These

| # | Incorrect Usage | Why |
|---|----------------|-----|
| 1 | Stretch or distort the logo | Breaks proportions and recognition |
| 2 | Rotate the logo | Breaks recognition and readability |
| 3 | Change the logo colors outside approved variants | Breaks brand consistency |
| 4 | Add drop shadows, bevels, or gradients | Looks cheap and harms legibility |
| 5 | Place on busy/low-contrast backgrounds | Logo becomes illegible |
| 6 | Add outlines or strokes | Breaks clean design |
| 7 | Rearrange icon and wordmark | Breaks approved layouts |
| 8 | Use the wordmark without the icon (except in body text) | Loses visual identity |
| 9 | Crop or mask the logo | Loses required elements |
| 10 | Place on pure white (#FFFFFF) background without adjusting colors | Contrast too harsh |
| 11 | Use low-resolution versions | Always use vector source |
| 12 | Add text to the logo | "Bloot Games", "Bloot App" — NO |
| 13 | Animate individual parts independently | Breaks cohesion |
| 14 | Use in a horizontal line of other logos smaller than equal | Wait, smaller — also no |
| 15 | Apply filters (blur, opacity, etc.) | Always 100% opacity |
| 16 | Place on a patterned background without a solid container | Logo must have clean contrast |
| 17 | Use the icon as a bullet point | Not a decorative element |
| 18 | Mirror/flip the logo for RTL | Logo stays the same in RTL and LTR |

## App Icon

### Design Specifications

| Property | Value |
|----------|-------|
| Shape | Rounded square (iOS/Android default) |
| Background | Gradient: #8B5CF6 → #6D28D9 (top-left to bottom-right) |
| Icon | Bloot mark (card-themed) centered |
| Icon color | #FFFFFF (White) with #F59E0B (Gold) accent |
| Border radius | iOS: continuous (super-ellipse), Android: adaptive icon |
| Safe zone | Center 80% of icon area |

### iOS App Icon

- Master size: 1024 × 1024px
- Include all required sizes: 180px, 120px, 87px, 80px, 60px, 58px, 40px, 29px, 20px
- No alpha/transparency
- Don't add device mockup frames

### Android Adaptive Icon

- Foreground: 108 × 108dp (safe zone: 72 × 72dp centered)
- Background: 108 × 108dp (full bleed, corners may be clipped)
- Monochrome: 108 × 108dp (for themed icons, Android 13+)
- Provide: mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi

### Icon Design Notes

- The icon should be **recognizable at 29px** (smallest iOS size)
- Avoid thin lines or small details that disappear at small sizes
- The card shape should be immediately identifiable
- Purple gradient background is required (not flat purple)
- White icon on purple gradient — gold accent for premium feel
- No text on the app icon (no "B" or "بلوت")

## Splash Screen

### Design Specifications

```
┌─────────────────────────────────────┐
│                                     │
│          Background: #0A0A0F        │
│                                     │
│                                     │
│              ┌──────┐               │
│              │      │               │
│              │ ICON │               │
│              │      │               │
│              └──────┘               │
│                                     │
│              BLOOT                  │
│              بلوت                   │
│                                     │
│                                     │
│                                     │
│                                     │
└─────────────────────────────────────┘
```

| Property | Value |
|----------|-------|
| Background | #0A0A0F (solid) |
| Icon | Bloot mark, centered, 120 × 120px (at 1x) |
| Wordmark "BLOOT" | Below icon, Inter Bold, 24px, #FFFFFF |
| Wordmark "بلوت" | Below icon, Cairo Bold, 24px, #FFFFFF |
| Icon position | Vertically centered, shifted 8% above optical center |
| Animation | Icon fades in (300ms) → wordmark fades in (200ms, 100ms delay) |
| Maximum display time | 2 seconds (then auto-dismiss) |
| No loading bar | Clean, minimal, brand-focused |

### iOS Launch Screen

- Use storyboard launch screen (not image-based)
- Same layout for all sizes (iPhone SE to iPhone Pro Max)
- Dark background only
- No status bar on splash

### Android Splash Screen

- Use Splash Screen API (Android 12+)
- Same layout as iOS
- Icon: 120dp centered (with animation zone)
- Background: #0A0A0F
- Animation: Icon scale-in (200ms), then app reveals

---

## Logo Animation

### Splash Screen Animation Sequence

```
Frame 0ms:      Empty dark background (#0A0A0F)
Frame 0-300ms:  Icon fades in (opacity 0 → 1, scale 0.95 → 1.0)
Frame 200-400ms: Wordmark fades in (opacity 0 → 1, translateY 4px → 0)
Frame 400-600ms: Gold accent on icon pulses once (opacity 0.6 → 1.0 → 0.6)
Frame 600ms+:   Hold, then app content reveals over logo
```

### Press/Touch Animation (Icon Only)

```
Frame 0ms:      Normal state
Frame 0-100ms:  Scale 1.0 → 0.95, opacity 1.0 → 0.9
Frame 100-200ms: Scale 0.95 → 1.0, opacity 0.9 → 1.0
Easing: spring(0.34, 1.56, 0.64, 1)
```

## Logo Typography

### English Wordmark: Inter

```
Font: Inter
Weight: Bold (700)
Size: Relative to context (not fixed px)
Letter-spacing: 0.08em (wider than body text)
Text-transform: UPPERCASE
Color: #FFFFFF (on dark) or #171717 (on light)
```

### Arabic Wordmark: Cairo

```
Font: Cairo
Weight: Bold (700)
Size: Relative to context (matches English wordmark height)
Letter-spacing: 0 (NEVER add letter-spacing to Arabic)
Color: #FFFFFF (on dark) or #171717 (on light)
```

### Letter-spacing Note

The English wordmark uses 0.08em letter-spacing to give it room to breathe and a premium feel. The Arabic wordmark uses **zero letter-spacing** because Arabic is a cursive script and letter-spacing destroys legibility.

**Never adjust letter-spacing on the Arabic wordmark. This is a non-negotiable rule.**

## Quality Checklist

Before finalizing any logo usage, verify:

- [ ] Correct color variant for the background
- [ ] Minimum size respected (not too small)
- [ ] Clear space maintained (1x icon height minimum)
- [ ] No distortion or stretching
- [ ] No unauthorized colors added
- [ ] No text overlaid on the logo
- [ ] No rotation of the logo
- [ ] File is vector (SVG) or high-resolution PNG (minimum 2x)
- [ ] Arabic wordmark has zero letter-spacing
- [ ] Icon is recognizable at the displayed size
- [ ] Contrast meets WCAG AA standards
- [ ] Background is not busy or low-contrast
