# Khaleeji Balout Game Mechanics

## Game Overview

Balout (بلوت) is a trick-taking card game popular in the Arabian Gulf (Khaleej) region. It is closely related to the French game Belote and is the most popular card game in Saudi Arabia, Kuwait, Bahrain, and Qatar.

| Attribute | Value |
|---|---|
| Players | 4 (2 teams of 2, partners sit across from each other) |
| Deck | Standard 52-card deck (no jokers) |
| Cards per player | 13 cards |
| Trick count | 13 tricks per deal |
| Modes | Sun (صن) and Hokm (حكم) |
| Winning condition | First team to reach target score over multiple deals |

### Player Positions

```
        North (Player 2)
West (P1)              East (P3)
        South (Player 4) — Dealer
```

- North-South form Team 1
- East-West form Team 2
- Partners sit opposite each other
- Dealer rotates clockwise after each deal

---

## Dealing

### Deal Procedure

1. Dealer shuffles the deck
2. Player to dealer's right cuts the deck
3. Dealer distributes cards in the following order:
   - First round: 5 cards to each player (clockwise, starting from dealer's right)
   - Second round: 4 cards to each player
   - Third round: 4 cards to each player
   - Total: 13 cards per player (5 + 4 + 4 = 13)
4. The **last card dealt** (to the dealer) is placed face-up on the table
5. This face-up card determines the initial trump suit for bidding purposes

### Card Distribution Verification

- 4 players × 13 cards = 52 cards (entire deck dealt)
- No remaining cards in the deck (unlike some Belote variants)

---

## Bidding Phase

After dealing, players bid to determine the game mode. Bidding proceeds clockwise starting from the player to the dealer's right.

### Bid Options

1. **Sun (صن)** — Also called "Ser" or "Saroo"
2. **Hokm (حكم)** — Also called "Hokom" or "Trump"
3. **Pass** — Decline to bid

### Bidding Rules

- Each player can bid Sun, Hokm, or Pass
- A player can only bid Hokm if they hold at least one card of the suit of the face-up card (the proposed trump suit)
- Once a player bids Hokm or Sun, bidding continues but subsequent players can only bid a "higher" bid
- **Bid hierarchy:** Hokm > Sun > Pass
- If all four players pass, the cards are re-dealt by the same dealer
- The first player to bid Hokm or the last player to bid Sun wins the bid

### Bidding Strategy Notes

- Sun requires more skill as there is no trump suit
- Hokm is more common and allows trump suit strategy
- A player bidding Hokm signals confidence in the trump suit
- Partners may signal each other through bidding patterns

## Sun Mode (صن)

### Rules

- **No trump suit** — all suits are equal in rank
- Target score: **Varies by mode** — 120 for Sun, 152+ for Hokm
- The bidding team MUST score more than the opposing team
- If the bidding team fails to exceed the opponent's score, they "fall" (تسقط) and the opposing team receives full points (152) plus any bonuses

## Hokm Mode (حكم)

### Rules

- A trump suit is designated (the suit of the face-up card, confirmed by the bidder)
- The bidding team must score more points than the non-bidding team
- Bonuses (bnaga/mosal) add to the point total
- If the bidding team fails to exceed the opponent's score, they "fall" and opponents receive all points

### Card Rankings in Hokm Mode

#### Trump Suit (حكم)

| Rank | Card | Points |
|---|---|---|
| 1st | Jack (J) | 20 |
| 2nd | 9 | 14 |
| 3rd | Ace (A) | 11 |
| 4th | 10 | 10 |
| 5th | King (K) | 4 |
| 6th | Queen (Q) | 3 |
| 7th | 8 | 0 |
| 8th | 7 | 0 |

**Trump suit total:** 20 + 14 + 11 + 10 + 4 + 3 = 62

#### Non-Trump Suits (عادي)

| Rank | Card | Points |
|---|---|---|
| 1st | Ace (A) | 11 |
| 2nd | 10 | 10 |
| 3rd | King (K) | 4 |
| 4th | Queen (Q) | 3 |
| 5th | Jack (J) | 2 |
| 6th | 9 | 0 |
| 7th | 8 | 0 |
| 8th | 7 | 0 |

**Non-trump suit total:** 11 + 10 + 4 + 3 + 2 = 30

### Total Base Points in Hokm

- 1 trump suit × 62 = 62
- 3 non-trump suits × 30 = 90
- **Base total:** 62 + 90 = 152

This is why Sun's target is often stated as 152 — it's the Hokm base total. But in Sun (no trump), the total is 120.

### Hokm Trick Rules

1. The player who won the bid leads the first trick
2. Players must follow suit if they can (mandatory)
3. If a player cannot follow suit, they may:
   - Play a trump card (to win the trick)
   - Discard any card (effectively conceding the trick)
4. The highest card of the led suit wins, UNLESS a trump card is played
5. If multiple trump cards are played, the highest-ranking trump wins
6. The winner of a trick leads the next trick
7. All 13 tricks are played (no early termination)

### Hokm Win Conditions

- If bidding team scores > non-bidding team: Each team gets their earned points (including bonuses)
- If bidding team scores ≤ non-bidding team: Bidding team "falls" — opponents get ALL base points (152) + ALL bonuses, bidding team gets 0

## Bonuses (مكافآت)

Bonuses only apply in **Hokm mode**, not in Sun mode.

### Bnaga (بنقة) — Consecutive Sequence

A sequence of 3 or more cards of the **same suit** in consecutive rank order.

| Sequence Length | Name | Points |
|---|---|---|
| 3 cards | Bnaga Thalatha (بنقة ثلاثة) | 20 |
| 4 cards | Bnaga Arba'a (بنقة أربعة) | 50 |
| 5+ cards | Bnaga Khamsa (بنقة خمسة) | 100 |

**Ranking for sequences (highest to lowest):** A, K, Q, J, 10, 9, 8, 7

**Rules:**
- Sequences must be in the same suit
- Only the LONGEST sequence in a suit counts (no splitting)
- If both teams have sequences of the same length, the team with the higher-ranking sequence wins
- Only the team with the higher sequence gets their bonus points; the other team's sequence is nullified
- Sequences are declared at the start of play (after bidding, before first trick)

### Mosal (مصل) — Four of a Kind

Four cards of the same rank.

| Rank | Name | Points |
|---|---|---|
| Jacks (J×4) | Mosal Jawj (مصل جوج) | 200 |
| Nines (9×4) | Mosal Tisa (مصل تسعة) | 150 |
| Aces (A×4) | Mosal Ace | 100 |
| Tens (10×4) | Mosal 'Ashra | 100 |
| Kings (K×4) | Mosal Malik | 100 |
| Queens (Q×4) | Mosal Malika | 100 |

**Rules:**
- Only one mosal can be claimed per hand per team (the highest value one)
- If both teams have a mosal, the higher-value mosal wins and only that team gets points
- Mosal is declared at the start of play along with sequences

### Bonus Comparison Rules

When both teams declare bonuses:
1. Compare mosal first — higher mosal wins; losing team's bonuses (including sequences) are nullified
2. If no mosal or equal mosal, compare longest sequence — longer sequence wins
3. If sequences are equal length, compare the highest card in the sequence
4. The winning team's bonuses count; the losing team's bonuses are nullified

## Complete Scoring Example

### Hokm Mode Example

Trump: Hearts

Team A (bidders): Holds sequences worth 50 points + base trick points of 90 = 140
Team B (opponents): Holds mosal of Aces (100 points) + base trick points of 62 = 162

Since Team B has the higher bonus (mosal > sequence), Team B's bonuses count and Team A's sequence bonus is nullified.

- Team B: 62 (tricks) + 100 (mosal) = 162
- Team A: 90 (tricks) + 0 (nullified) = 90

Team A bid but scored less (90 < 162), so Team A "falls":
- Team B gets: 152 (base) + 100 (mosal) = 252
- Team A gets: 0

## Game Flow State Machine

```
┌─────────┐
│ WAITING │ ← Room created, waiting for 4 players
└────┬────┘
     │ 4 players joined, host starts
     ▼
┌─────────┐
│ DEALING │ ← Cards distributed to all players
└────┬────┘
     │ Deal complete, face-up card shown
     ▼
┌─────────┐
│ BIDDING │ ← Players bid Sun, Hokm, or Pass
└────┬────┘
     │ Bid resolved (Sun or Hokm chosen)
     ▼
┌──────────────┐
│ BONUS_CLAIM  │ ← Players declare sequences/mosal (Hokm only)
└──────┬───────┘
       │ Bonuses resolved
       ▼
┌─────────┐
│ PLAYING │ ← Trick-by-trick play (13 tricks)
└────┬────┘
     │ All 13 tricks played
     ▼
┌─────────┐
│ SCORING │ ← Calculate points, resolve fall/success
└────┬────┘
     │ Score applied to running total
     ▼
┌───────────┐     ┌───────────┐
│ CHECK_WIN │────▶│ GAME_END  │ ← Team reaches target score
└─────┬─────┘     └───────────┘
      │ No winner yet
      ▼
┌──────────┐
│ NEW_DEAL │ ← Rotate dealer, start next deal
└─────┬────┘
      │
      ▼
┌─────────┐
│ DEALING │ ← (loop back)
└─────────┘
```

### State Descriptions

| State | Description | Duration | Player Actions |
|---|---|---|---|
| WAITING | Room lobby, waiting for 4 players | Variable | Chat, configure settings, leave |
| DEALING | Cards being distributed | ~2 seconds (automated) | None (watch deal animation) |
| BIDDING | Players choose Sun/Hokm/Pass | 10-30 seconds per player | Bid Sun, Bid Hokm, Pass |
| BONUS_CLAIM | Players declare sequences/mosal | 15-30 seconds | Declare bonus, confirm |
| PLAYING | Trick-by-trick gameplay | Variable (~5-15 min) | Play card, view hand |
| SCORING | Points calculated and displayed | ~5 seconds | View score breakdown |
| CHECK_WIN | Check if team won the game | Instant | None |
| GAME_END | Game over, winner declared | Variable | Rematch, leave room |
| NEW_DEAL | Transition to next deal | ~2 seconds | None |

## Special Rules and Edge Cases

### Mosal with 3 Cards (مصل ثلاثي)

In some variants, 3 of a kind does not count as a mosal. In standard Khaleeji Balout, **only 4 of a kind** counts as a mosal.

### Last Trick Bonus

The team that wins the **last trick** (13th trick) receives a **10-point bonus** in some variants. This is NOT standard in Khaleeji Balout but may be a house rule. For Bloot implementation: include as optional room setting.

### Running Score and Target

- Teams accumulate points across multiple deals
- The first team to reach or exceed the **target score** wins the game
- Default target: **152 points** (configurable in room settings)
- Some groups play to 250, 300, or other targets

### Re-deal Conditions

- All four players pass during bidding → re-deal by same dealer
- Misdeal (wrong card count) → re-deal
- Connection loss of a player → pause game, wait for reconnection (60 seconds), then AI takes over or game is abandoned

### Etiquette Rules (for Bloot implementation)

- Players cannot communicate about their hands to partners (voice chat is general, no whispering)
- In ranked games, voice chat may be restricted to prevent cheating
- Timer per turn: 30 seconds default; auto-play lowest card if time expires

## Card Representation for Implementation

### Suit Encoding

```dart
enum Suit { hearts, diamonds, clubs, spades }

// Arabic names
const suitNames = {
  Suit.hearts: 'قلوب',
  Suit.diamonds: 'ديناري',
  Suit.clubs: 'سان',
  Suit.spades: 'باستوني',
}
```

### Rank Encoding

```dart
enum Rank { seven, eight, nine, ten, jack, queen, king, ace }

// Display order (as shown in hand, low to high)
// Point values depend on game mode and trump status
int getCardPoints(Rank rank, {bool isTrump = false, bool isSunMode = false}) {
  if (isSunMode || !isTrump) {
    switch (rank) {
      case Rank.ace: return 11;
      case Rank.ten: return 10;
      case Rank.king: return 4;
      case Rank.queen: return 3;
      case Rank.jack: return 2;
      default: return 0;
    }
  } else {
    // Trump suit in Hokm mode
    switch (rank) {
      case Rank.jack: return 20;
      case Rank.nine: return 14;
      case Rank.ace: return 11;
      case Rank.ten: return 10;
      case Rank.king: return 4;
      case Rank.queen: return 3;
      default: return 0;
    }
  }
}
```

### Trick Winner Determination

```dart
Card determineTrickWinner(List<PlayedCard> trick, Suit trumpSuit, bool isSunMode) {
  Suit leadSuit = trick.first.card.suit;

  // In Sun mode: no trump, highest card of lead suit wins
  if (isSunMode) {
    return trick
        .where((p) => p.card.suit == leadSuit)
        .reduce((a, b) => getRankOrder(a.card.rank, isTrump: false) >
                          getRankOrder(b.card.rank, isTrump: false) ? a : b)
        .card;
  }

  // In Hokm mode: check for trumps first
  var trumps = trick.where((p) => p.card.suit == trumpSuit);
  if (trumps.isNotEmpty) {
    return trumps.reduce((a, b) => getRankOrder(a.card.rank, isTrump: true) >
                                   getRankOrder(b.card.rank, isTrump: true) ? a : b)
                 .card;
  }

  // No trumps played: highest of lead suit wins
  return trick
      .where((p) => p.card.suit == leadSuit)
      .reduce((a, b) => getRankOrder(a.card.rank, isTrump: false) >
                        getRankOrder(b.card.rank, isTrump: false) ? a : b)
      .card;
}
```
